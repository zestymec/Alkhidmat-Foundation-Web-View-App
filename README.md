# My First React Native Project 🚀
**Project:** Alkhidmat Foundation Mobile Web-App

Hi, I'm **Umer Aziz**! Today marks a huge milestone in my journey as a developer. I successfully built and ran my very first cross-platform mobile application from scratch.

## 🌟 What I Achieved Today
As a beginner in the mobile dev world, I took on the challenge of setting up a complex environment and building a functional app. Here is a summary of my progress:

* **Full Environment Setup:** I configured my Mac to handle both **iOS (Xcode)** and **Android (Android Studio)** development.
* **Version Management:** I learned how to handle version compatibility by sticking with a stable release (**React Native 0.74.0**) that works perfectly with my current tools.
* **Dual-Platform Deployment:** I successfully launched the app on both the **iPhone Simulator** and **Android Emulator** simultaneously.
* **Real-World Problem Solving:** I encountered and fixed deep-level build errors (like the `StripDebugSymbols` Gradle error) by modifying project configurations—a true "Engineering" moment!
* **The App:** I created a functional Mobile Web-View for the **Alkhidmat Foundation**, including a custom loading spinner (`ActivityIndicator`) to enhance user experience.

## 🛠️ Tools & Technologies
- **Framework:** React Native
- **Language:** JavaScript / TypeScript
- **Environment:** macOS (Intel i7)
- **Platforms:** iOS & Android
- **Key Library:** `react-native-webview`
